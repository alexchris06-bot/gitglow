# GITGLOW
ANIMATOR COMMIT & VISUALISATOR PERKEMBANGAN KODE PROGRAM

Sebuah web interaktif yang menampilkan riwayat commit dari suatu repositori. Karena statistik bawaan GitHub memiliki interface yang kaku dan kurang interaktif (hanya berupa kotak-kotak hijau abstrak), maka web ini mengubah tampilan riwayat tersebut menjadi animasi visual interaktif. Dengan demikian, pengguna dapat melihat bagaimana struktur projek yang dikerjakan tumbuh dari hari ke hari, apa pun aktivitas yang dilakukan pada projek secara interaktif.
